Video Upload Tool

運営者が自分のYouTubeチャンネルに動画をアップロードし、公開日時を予約するための個人用ツールです。運営者本人以外は利用できません。

プライバシーポリシー

  • 利用する情報：YouTube Data API を通じて、運営者本人のチャンネルへの動画のアップロード、公開日時の予約、サムネイルの設定に必要な権限のみを利用します。
  • 情報の保存：認証情報は運営者のパソコン内にのみ保存し、外部に送信・共有しません。
  • 第三者への提供：取得した情報を第三者に提供・販売することはありません。
  • 利用者：本ツールの利用者は運営者本人のみです。
  • Google API の利用：本ツールによる Google API から受け取った情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
